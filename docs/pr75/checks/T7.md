# T7 完了条件チェック

タスク: 等価性テストの拡充（型行を持つ実Excel・messaging 系の並走。旧 V-1 を統合）
参照文書: 仕様リスト SS-05/MS-04、解説書 §6・§7
変更対象: `src/test/.../ExcelToYamlEquivalenceTest.java`（または新規等価性テスト）、テスト用 Excel/YAML

## 実施手順

1. 型行を持つ実 Excel（`FileSupportTest.xls`、`VariableLengthFileParserTest.xls` 等）を変換ツールで YAML 化し、`BasicTestDataParser`（Excel）と `YamlTestDataParser`（YAML）の読込結果が等価であることを検証する並走テストを追加する。
2. messaging 系の実 Excel（FW制御ヘッダ・電文ボディ・複数データ行を含む。`MessagingRequestTestSupportTest.xls`、`MessageParserTest.xls` 等）を変換し、`directives`/`fwHeader`/電文ボディが Excel と YAML で等価であることを検証する並走テストを追加する。
3. 乱数インタープリタ等で等価比較不可のケースは対象外とし、その理由をテストの Javadoc に明記する（決定的な値で代替確認する）。
