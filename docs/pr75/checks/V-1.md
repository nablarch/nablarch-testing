## 検討した選択肢・除外したケース

### 等価性確認の対象外ファイル

NTF 統合テスト（バッチ実行・メッセージング・HTTP）が必要でテスト環境制約があるため、以下を `ExcelToYamlEquivalenceTest` の対象外とした。変換ツールの出力自体は成功し、YAML ファイルは生成済み。

| ファイル | 等価性確認 | 理由 |
|---|---|---|
| `*BatchSampleTest.xls` 等 | 未実施 | バッチ実行環境が必要 |
| `*MessagingTest.xls` 等 | 未実施 | メッセージング環境が必要 |
| `*HttpRequestTest.xls` 等 | 未実施 | HTTP リクエスト実行環境が必要 |
| `BasicTestDataParserTest.xls` | 実施済み（全等価確認） | `ExcelToYamlEquivalenceTest` で 11 ケース確認 |

|---|---|---|
| withoutGroupId | 実施済み | 等価 |

| 指摘 | 重要度 | 対応内容 |
