# T1 完了条件チェック

タスク: フィールド型記法を日本語名称に統一。
参照: 設計書 §5、スキーマ `$defs/field_def/type`、仕様リスト IV-12。

## 背景と決定

YAML のフィールド型を記号でなく日本語名称（`半角`／`全角`／`数値` 等）でそのまま書けるようにする。従来は `unit-test-yaml.xml` の `dataTypeMapping`（記号 identity mapping）が記法→型記号の変換を肩代わりしていたが、これを廃し、`BasicDataTypeMapping` 本来の責務（設計書記法→型記号変換）に戻す。

```mermaid
flowchart LR
  YAML["YAML<br/>type: 半角/全角/数値"] --> MAP["BasicDataTypeMapping<br/>（設計書記法→型記号）"] --> FRAG["DataFileFragment<br/>型変換"]
```

## 実施手順（TDD）

1. RED: `dataTypeMapping` を登録しない設定で、`type: 半角`・`type: 全角`・`type: 数値` を持つ固定長/可変長 YAML を読み込み、`DataFileFragment` の型変換が例外なく成功することを検証するテストを追加し、失敗を確認する。
2. GREEN: `unit-test-yaml.xml` から `dataTypeMapping`（記号 identity mapping）の `<component>` 定義を削除する。
3. スキーマ `$defs/field_def/type` を、更新版スキーマ `03` の定義（`type: string`, `minLength: 1`, pattern なし）に置き換える。
4. `YamlSchemaValidationTest` に、`type: 半角` 等の日本語名称が valid であることを検証するケースを追加する。

変更対象ファイル: `src/test/resources/unit-test-yaml.xml`、`src/main/resources/nablarch/test/ntf-testdata-yaml-schema.json`、`src/test/.../YamlSchemaValidationTest.java`、`src/test/.../YamlTestDataParserTest.java`（または同等のファイル読込テスト）。
