## 突合方法

1. 両者の `target/site/jacoco/jacoco.xml` から、`package`/`sourcefile`/`line` を辿って `mi>0` または `mb>0` の行を全件抽出する（`(ファイル, 行番号, mi, mb)`）。クラス単位の `jacoco.csv` は使わない。
2. `src/main` の各ファイルについて `git show origin/develop:<path>` と `git show HEAD:<path>` を取り、`difflib.SequenceMatcher`（`autojunk=False`）の `equal` オペコードから **baseline 行番号 → PR 行番号** の写像を作る（行番号ずれの吸収）。両版が同一内容のファイルは恒等写像。
3. PR 側の未達行を1件ずつ判定する。
   - 写像先が無い（＝PR で新規追加・変更された行） → **PR-ONLY**
   - 写像先はあるが `mi` または `mb` が baseline より増えている → **WORSE**
   - それ以外（baseline でも同じだけ未達） → 既存未達として除外
